# Laundry Service Website

A simple and responsive Laundry Service Booking website built using HTML, CSS, and JavaScript.

## 📌 Project Overview

This project provides an online interface where users can browse different laundry services, add required services to their cart, view the total amount, and book the selected services.

The website includes a clean two-column layout similar to a real laundry service booking platform.

## ✨ Features

- Browse multiple laundry services
- Add services to the cart
- Skip services
- Automatically move to the next service
- Display added services in the cart
- Automatically calculate total amount
- Book laundry services using customer details
- Full Name, Email ID and Phone Number fields
- Booking confirmation message
- Logout button
- Responsive design for different screen sizes
